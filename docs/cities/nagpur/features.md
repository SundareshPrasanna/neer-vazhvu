# Nagpur - Features

City thirteen, live. Sources behind each surface: `data-sources.md`. Measured depth:
`parity-scorecard.md`.

## What kind of city this is

Nagpur drinks a reservation inside a state power and irrigation project. Four of NMC's five treatment
plants (546 of 786 MLD) run on Pench water released from Totladoh, the Pench hydro-electric reservoir
shared with Madhya Pradesh, into the Navegaon Khairi pick-up dam; the fifth (240 MLD) lifts from the
Kanhan. NMC's share is 190 Mcum a year under the WRD resolution of 19 March 2020. The city's own
rivers, the Nag, the Pili and the Pora, carry its storm water and sewage to the Kanhan.

## Refresh homes

| Layer | How it refreshes |
|---|---|
| Reservoir cards | Daily, step 2c of the local scheduled job (`scrape_pravah_dams.py --city nagpur --supabase`), because the department's host does not answer GitHub runners. Watched by two Supabase freshness checks (`nagpur:reservoir:totladoh`, `nagpur:reservoir:navegaon_khairi`) and the file check `nagpur-dam-storage`, each at 4 days |
| Rainfall | Daily Open-Meteo fill (`rainfall-recent-refresh.yml`); the IMD gridded base is regenerated by hand from a residential connection, because IMD's server refuses the quarterly workflow's runner |
| Groundwater telemetry | By hand (`build_nwdp_gw_stations.py --city nagpur` after `build_ingres_gwr.py --city nagpur`) |
| Everything else | Edition-driven: the Headwaters registry watches each upstream and opens an issue when a new edition appears |
